# 🎵 Carpeta de Recursos Multimedia (`public/assets/`)

Aquí es donde debes colocar tu música y tus fotos reales para que la aplicación las tome de forma automática:

### 1. Música Romántica de Fondo
- **Nombre requerido:** `cancion.mp3`
- **Ruta:** `public/assets/cancion.mp3`
- **Detalle:** Es la canción que comenzará a reproducirse suavemente cuando Ariana toque el botón *"Toca para abrir tu sorpresa"*.

### 2. Fotos de Recuerdos
Coloca tus fotos favoritas con estos nombres (o agrega más y actualiza `src/data/contenido.js`):
- `foto1.jpg` -> Portada / Primer recuerdo especial
- `foto2.jpg` -> Foto en la feria / antojitos
- `foto3.jpg` -> Foto bailando o en un evento
- `foto4.jpg` -> Foto espontánea o de una noche especial
- `foto5.jpg` -> Foto sonriendo juntos

> **Nota:** Si alguna foto aún no está colocada, la aplicación cuenta con un elegante diseño de respaldo (*placeholder* con degradados románticos, destellos y mensajes) para que nada se rompa visualmente mientras las agregas.
